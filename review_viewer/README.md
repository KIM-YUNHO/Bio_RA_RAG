# 전처리 문서 시각 검토

검토 페이지는 원본 PDF와 저장된 전처리 결과를 비교하는 읽기 전용 도구다. 질문 기능과 모델 호출은 없다. 질의응답은 별도의 [메인 RAG 서비스](../rag_service/README.md)에서 제공한다.

프로젝트 루트의 PowerShell에서 실행한다.

```powershell
.\.venv\Scripts\python.exe -X utf8 -B -m review_viewer --run data/preprocessed/ra_workflow_native_v1_2026-10-08 --port 8766
```

브라우저에서 <http://127.0.0.1:8766/>을 연다. 메인 서비스와 별도 프로세스이며 서버를 종료하면 검토 페이지만 종료된다.

## 확인할 수 있는 내용

- 원본 PDF와 추출 결과를 나란히 비교하고 영역을 클릭해 상세 결과 확인
- 본문·표·그림 및 여러 패널을 묶은 논리적 그림 부모의 위치 표시
- 최종 표현, 기본 추출, native 원문, 저장된 Qwen 응답 및 실제 입력 crop 비교
- 캡션·본문 참조·패널 관계, 청크 내용, 검색 포함 여부와 제외 사유 확인
- 문서 내 검색과 표·그림 / 검토 필요 페이지 필터
- 현재 문서·페이지·영역의 링크 복사와 원본 PDF 열기
- 메인 서비스의 인용에서 해당 원본 영역 열기. 청크 버전이 다르면 오류 표시

현재 연결된 결과는 5문서·523페이지·1,578청크이며 검토 항목 164개가 남아 있다. 자동 추출 내용의 정확성을 승인하는 화면은 아니다. 검토 항목 수와 검색 제외 단위 수는 서로 다른 집계다.

## 다른 완료 결과 연결

`--run`에는 완료된 workflow 폴더 또는 extraction/labels 체크포인트 폴더를 지정한다. 후보 청크가 별도 위치에 있으면 `--candidate <후보 폴더>`를 함께 지정한다. 원본 PDF와 체크포인트가 그대로 있어야 한다. 입력 결과와 후보 청크의 해시·연결 관계가 맞지 않거나 처리 중인 체크포인트는 거부한다.

로컬 주소에만 접속을 허용하고 원본·전처리·색인은 변경하지 않는다. 원본 이미지는 요청 시 로컬 렌더링한다. OCR·VLM·임베딩, 외부 API·CDN·외부 폰트를 사용하지 않는다. 문서 업로드·추출 수정·승인 저장은 제공하지 않는다.

## 검증

```powershell
.\.venv\Scripts\python.exe -X utf8 -B -m unittest discover -s tests -p test_review_viewer.py
```

원본·영역·표·그림·필터 검증 기록은 [ui_checks.json](../tmp/review_viewer_checks/ui_checks.json)에 있다. 메인 질의응답에서 별도 검토 페이지로 이동하는 검증은 `tmp/rag_service_checks/`에 기록한다. 이전 `qa_ui_checks.json`은 검토 페이지 안에 질문 기능이 있던 구버전의 기록이며 현재 구조와 구분한다.
