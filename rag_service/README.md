## 실행

RA 경로는 `--mode ra --llm-model gpt-5.6-luna --guidelines data/guidelines/ra_guidelines_native_2026-10-11_v1 --port 8775`를 지정한다. 계획·생성·내부 주장 검토는 선택한 같은 모델이며 요청당 최대 3회다. Luna는 추론 `none`으로 실행한다. `--llm-model`을 생략하거나 `gpt-4o-mini`를 지정하면 기존 mini다. 모드를 생략한 실행은 기존 경로다. 아래 기존 서비스 적용·평가 수치는 당시 기록이며 신규 경로의 품질 측정이 아니다.

질의응답과 원본 검토는 별도 로컬 서버다.

~~~powershell
.\.venv\Scripts\python.exe -X utf8 -B -m rag_service --run data/versions/01_pilot_baseline_2026-10-10/embedded/rag_finalization_2026-10-10_v2 --port 8765 --retrieval-pages 5 --review-url http://127.0.0.1:8766
.\.venv\Scripts\python.exe -X utf8 -B -m review_viewer --run data/versions/01_pilot_baseline_2026-10-10/embedded/rag_finalization_2026-10-10_v2 --port 8766
~~~

메인 화면은 상품·기관 필터, 문서별 검색 가능 청크 수, 질문 처리 단계와 원본 영역 링크를 제공한다. 제품정보 문서군은 5상품에 공통으로 기본 검색에 포함한다. ‘보조 문서까지 검색 범위 확대’ 옵션은 이미 처리된 다른 비기본 자료의 범위를 넓힌다. 평가 보류 문서나 검토 중인 표 표현은 이 옵션으로 복원하지 않는다.

일반 문서는 검증한 native 표현 또는 가벼운 OCR을 사용한다. 표·그림의 제목과 문맥은 같은 원문 버전·페이지·영역에 연결하며, 복잡 영역은 양성 구조 근거가 있을 때만 Qwen으로 보완한다. 추론 완료·문자 인용 일치·구조 검사·임상 의미 판정은 별도 상태다.

## 검색과 답변

공통 경로는 질문 해석 → 상품·기관별 검색 계획 → BGE-M3/BM25 → 예산 내 원문 문맥 선택 → 답변 생성 → 원문 인용·조건 검사다. 검색 페이지 수 기본값은 5이며 1~10을 허용한다.

임상 소제목은 원래 source unit의 문자 위치를 보존하며 분리한다. 직접 검색된 표가 연결 문맥과 중복돼도 직접 검색 우선순위를 유지한다. 표를 발췌할 때는 원문 헤더와 필요한 병합 행 전체를 유지하고, 공급되지 않은 원문 구간을 명시한다. 문자 중간에서 잘라 인용하거나 빈 셀을 채우지 않는다.

답변에는 검사한 값과 용량·비교군·분석·시점·투여 경로·간격 등의 원문 조건을 표시한다. 문자·조건 인용 실패 시 같은 근거로 한 번만 교정하며 해당 호출도 사용량에 기록한다. 명시적으로 요청한 조건과 충돌하는 값은 답변에서 제외한다. 인용 검사 통과가 임상 의미나 행·열 귀속의 정확성을 자동 인증하지는 않는다.

## API 성능평가

사용자 지정에 따라 성능평가는 **OpenAI API gpt-4o-mini**를 사용한다. 서비스 기본 답변 제공자는 기존 로컬 Ollama 설정이며 평가 제공자와 구분한다. 가용성 확인 호출, 자동 HTTP 재시도, 무제한 재평가를 하지 않는다. 공개 RA 출처·원본 해시·보류 제외를 확인한 뒤 평가하며, 프로젝트 일일 기록은 다른 계정 사용량을 포함하지 않는다.

~~~powershell
# 공개 출처 감사만 수행: API 호출 없음
.\.venv\Scripts\python.exe -X utf8 -B tmp/public_source_regression.py

# 향후 생성 계약을 변경한 뒤 평가할 때의 예시: 새 해석+답변 최대 2회
.\.venv\Scripts\python.exe -X utf8 -B -m eval.ra3_openai_eval --release data/versions/01_pilot_baseline_2026-10-10/embedded/rag_finalization_2026-10-10_v2 --out data/runs/q012_followup_new --case-id Q012 --max-api-calls 2
~~~

평가는 원문 정답·루브릭을 생성 요청에 넣지 않는다. 검색 페이지 적중, 실제 공급 문맥, 인용 검사, 원문에 따른 답변 판정을 분리해 기록한다. 이번 12개 개발 문항과 실패 문항별 후속 실행은 전체 상품의 임상 일반화나 미노출 문서 성능을 측정하지 않는다. 단계별 코드·응답·호출 수를 고정하고, 서로 다른 코드의 결과를 한 번의 전체 평가 점수로 합치지 않는다.

## CLI

~~~powershell
.\.venv\Scripts\python.exe -X utf8 -B -m rag.pipeline --run data/versions/01_pilot_baseline_2026-10-10/embedded/rag_finalization_2026-10-10_v2 --query "EMA 문서에서 SB17-1001 시험의 투여 용량과 경로는?" --output data/runs/my_rag_answer_001.json
~~~

상품·기관·문서 및 비기본 문서 포함 옵션으로 범위를 제한한다. RA 경로는 질문 결과를 파일에 저장하고 최근 20개를 메모리에 복원한다. 과거 결과도 ID로 조회할 수 있다. 원본 검토 서버는 OCR이나 모델을 실행하지 않는다. 새 문서 처리 절차는 [전처리 워크플로우](../docs/preprocessing/LOCAL_PDF_WORKFLOW.md)를 따른다.


현재 제품별 문서/전체/기본 검색 청크는 SB17 31/3,059/2,702, ABP654 21/2,408/1,779, CTP43 23/2,955/2,507, BMAB1200 10/1,090/917, BAT2206 7/576/430이다. 총 기본 검색 범위는 8,335청크다. BAT2206의 FDA 라벨도 기본 검색으로 공급되며, 상품별 핵심 라벨 질의는 문서 고정 없이 API 평가했다. 9개 보류 문서는 계속 제외한다.

API ID 선택 경로는 원문 헤더·연결 시험 제목·값을 포함한 문장으로 조건을 보충하고, 관계가 없는 표/시험/비교 조건을 차단한다. 표 머리글을 수치 답으로 선택하지 못하게 하고, BMI 복합 단위와 온전한 CI 셀을 보존한다. 명시적인 다중 비교 및 군별 PK 분석집단 인원 요청에 일부만 답한 경우 원문 헤더로 누락을 확인하여 부분 답변으로 표시한다. 최신 회귀는 539개 통과했다. 기본 로컬 Ollama 경로의 실제 답변 성능은 이번 OpenAI 결과로 인증하지 않았다. 단계별 실제 API 사용량은 최신 평가 기록과 `data/runs/model_quota/` 장부에서 확인한다.


마지막 OpenAI 추가 평가는 기존 응답 근거에 없던 승인 문서 6버전을 사용했다. 핵심 사실 원문 확인은 4/6이며 FDA 2문항은 보완이 필요하다. 개발 실패를 수정한 회귀이며 독립 일반화 성능으로 해석하지 않는다. 이후 검사만 재적용해 FDA 통지 내용의 불완전한 항목은 제외하고, 소아 적응증의 잘못된 출처는 보류했다. 현재 검사 코드로 새 답변 생성은 재평가하지 않았다. 실제 사건(시판 통지/라벨 제출)과 허가 대상(소아 적응증/PREA)을 원문으로 구분하며, 관련 검사는 직접 인용 서비스 경로에도 적용한다. 전처리·임베딩 실행 완료와 표/그림 의미 검토 상태는 별도로 유지한다.
