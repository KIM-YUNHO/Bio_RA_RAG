## 확인된 문제 1: 원문의 잘못된 표 번호가 다른 시험의 표를 끌어온다

### EMA ABP 654, 본문 45페이지 → Table 5, 44페이지

45페이지 원문은 건선 환자의 **20190232** 시험을 설명하고, week 28까지 최저혈중농도 결과를 말하면서 `see Table 5`라고 쓴다. 하지만 실제 44페이지 Table 5는 건강인 **20190230** 시험의 AUC/Cmax 분석표다. 45페이지에는 최저혈중농도 Table 7도 별도로 존재한다.

원문 PDF에 실제로 Table 5라는 번호가 있으므로 OCR이 숫자를 잘못 읽어서 생긴 연결이 아니다. 현재 연결기는 문서·버전과 표 번호를 맞추지만, 이 경우 서로 다른 시험·지표라는 충돌을 막지 않는다. 그 결과 해당 문장이 Table 5의 검색용 헤더에도 들어간다.

고정 청크 재현 `psoriasis_ref_table5`에서:

1. 45페이지 건선 시험 본문을 선택했다.
2. `linked_visual_candidate`로 44페이지 Table 5가 들어왔다.
3. 그 표의 건강인 시험 제목 원문(42페이지)도 함께 들어왔다.
4. 실제 최저혈중농도 Table 7은 색인에 있지만 이 패킷에는 들어오지 않았다.
5. 후속 `same_study_context`에 Table 7을 언급한 45페이지 문장이 들어와도, 현재 순서에서는 시각 링크 확장이 이미 끝난 뒤여서 그 링크를 다시 따라가지 않았다.

이 재현은 잘못된 표가 생성 입력으로 들어갈 수 있다는 증거다. 전체 검색이 Table 7을 직접 찾거나 추가 조사 단계가 보완할 가능성은 있으며, 최종 답변이 반드시 틀린다는 뜻은 아니다.

### EMA ABP 654, 본문 103페이지 → Table 47, 101페이지

103페이지 원문은 **20190232** 시험의 ADA별 PASI 개선을 설명하면서 Table 47을 가리킨다. 실제 Table 47은 **20190230** 시험의 clearance 분석이다. 역시 원문 PDF에도 그 참조 번호가 인쇄돼 있다.

`psoriasis_ref_table47` 재현에서 101페이지 Table 47이 `linked_visual_candidate`로 들어왔다. 104페이지에는 PASI 개선을 다룬 Table 50이 있지만, 원문 참조 번호를 임의로 교정하지는 않았다.

## 확인된 문제 2: 새로운 시험 제목을 놓쳐 이전 시험을 계속 상속한다

EMA 보고서 83페이지에는 `Single dose PK study 20190230` 제목이 있다. 다음 84페이지에는 굵은 제목으로 `Clinical Ps study 20190232`가 등장한다. 하지만 현재 제목 인식기 `identify()`는 이 제목을 `sections-8`과 `sections-9` 모두에서 인식하지 못한다. `Ps`를 포함한 제목 형태가 시험 제목 규칙에 들어가지 않는 것이 직접 재현된다.

이후 일부 표는 캡션에 20190232가 적혀 있어도 헤더·제목 앵커에는 20190230이 남는다. 예를 들어 103페이지 Table 49는 캡션과 원문 모두 20190232의 ADA별 최저혈중농도 표인데, 상속 제목은 83페이지의 20190230이다.

`psoriasis_table49` 재현에서는 해당 표를 읽을 때 **잘못 상속된 20190230 원문 제목이 `source_heading`으로 실제 공급**됐다. 메타데이터에서만 충돌하는 문제가 아니라, 인용 가능한 제목 근거 자체가 잘못 붙는 경로다. 같은 시험 문맥 확장도 이 제목 앵커를 기준으로 동작한다. 단, 확장된 모든 본문이 다른 시험에 속한다고 단정할 수는 없다. 제목 앵커 자체가 오염돼 있기 때문이다.

15개 표 청크의 캡션/상속 시험 충돌 중 14개가 이 EMA 보고서에 있고, 나머지 1개는 FDA ABP 654 심사 문서의 35페이지 Table 8이다. FDA 항목은 저장된 명시적 ID 충돌을 확인했으며, 이 문서의 모든 주변 페이지까지 별도로 시각 판정한 것은 아니다.

본문→표 충돌 후보 3개 중 Table 49 참조 자체는 20190232의 표를 가리키는 것으로 보인다. 이 후보는 독립적인 잘못된 표 번호 사례가 아니라 상속된 제목이 틀려 발생한 경고로 구분한다.

## 정상 작동한 부분: 필요한 원문 조건과 표 내부 문맥은 공급할 수 있다

`healthy_table5` 재현에서 44페이지 건강인 PK Table 5를 시작점으로 잡자, 42페이지의 실제 시험 설계 본문과 43페이지의 채혈 일정 본문이 함께 들어왔다. 42페이지에는 **90 mg SC 단회투여, Day 1, US/EU 비교약, 무작위배정·이중눈가림·3군·평행군** 정보가 있다. 페이지를 넘는 제목 복원과 용량·경로 보강은 실제 작동한다.

또한 Table 49 청크에는 값 셀뿐 아니라 방문 시점, 군·ADA 상태 열 헤더, ng/ml 단위, 양성·음성 정의 각주가 함께 들어 있다. 이번에 확인한 문제를 표 전체의 값·조건이 항상 분리된다는 문제로 일반화하면 안 된다.

검색용 `[referring_sentence]` 헤더 문자열은 현재 생성 메시지에 직접 복사되지 않았다. 그러나 그 연결을 통해 다른 표를 추가하고, 제목 앵커로 원문 제목을 복원하는 경로가 실제 생성 입력에 영향을 준다.

## 별도 문제: 조건은 들어왔지만 최종 검증에서 빠지는 사례

저장된 E03 비교 질문에는 SB17-1001의 체중·BMI 선정 기준이 E16(38페이지)으로 공급돼 있었다. 해당 원문에는 체중 60.0–90.0 kg, BMI 19.0–29.9 kg/m²와 screening/Day −1 조건이 함께 있다.

그런데 이 기준을 서술한 주장은 `claim_quantity_value_or_unit_not_in_final_citations`로 제거됐다. ABP 654의 선정 기준 주장도 같은 사유로 제거됐다. 두 주장에 대해 현재 `ra_quantities.check()`를 다시 실행해 동일한 거절을 재현했다.

따라서 이 두 건은 필요한 근거가 검색·공급되지 않은 사례가 아니다. 선택 인용/수치·단위 검증 단계의 별도 조사 대상이다. 이번 점검에서는 검증 규칙을 완화하거나 원문 값을 교정하지 않았고, 단위·범위 표기 처리의 정확한 수정 지점까지 확정하지 않았다.

## 개선 우선순위

1. **시험 경계와 충돌 처리:** 레이아웃·원문이 뒷받침하는 시험 제목을 인식하고, 캡션의 명시적 시험번호가 상속 제목과 충돌하면 이전 제목을 확정 근거로 공급하지 않도록 한다. 한 문서의 제목 표현만 추가하는 수정에 그치지 않도록 한다.
2. **본문→표 연결 검증:** 번호가 같아도 시험·대상군·지표가 충돌하면 연결을 보류한다. 원문의 표 번호를 몰래 바꿔 정답 표로 연결하지 않고, 원문 참조 오류/불확실성을 보존한다.
3. **확장 후의 필요한 표 공급:** 새로 추가한 본문에 명시적 표 참조가 있으면, 제한된 추가 연결을 검토한다. 기존 범위·예산·중복 제한과 충돌 검증을 유지한다. 이번 재현은 전체 검색이 실패할 때만 생기는 문맥 공백을 보여 주므로 전체 질문 평가도 함께 필요하다.
4. **공급 이후의 조건 손실 추적:** 체중·BMI 사례처럼 근거·선택 인용·최종 주장 사이의 값을 비교하고, 수치·단위 표기 문제를 사실 지지 검사와 함께 검증한다.

## 해석의 한계

전체 구조 검사는 현재 지정 릴리스 전부를 대상으로 했지만, 원문의 의미를 전수 판정하지 않았다. 특히 ID가 없는 표·그림과 문맥 후보는 별도 검토가 필요하다. 4건의 고정 청크 재현은 통제된 진단이고 검색 recall/최종 오답률 측정이 아니다. 새로운 생성·독립 전문가 채점·운영 서버 평가를 실행하지 않았다. 생산용 코드는 수정하지 않았다.
