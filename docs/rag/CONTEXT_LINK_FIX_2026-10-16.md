# 문맥 연결·선정 기준 검증 수정 — 2026-10-16

[감사에서 확인한 문제](CONTEXT_LINK_AUDIT_2026-10-16.md)에 대한 코드 수정이다. RA 파이프라인 버전은 `ra-research-rag-4.10.2`다. 현재 지정된 04 릴리스 파일과 실행 중 서버는 변경하지 않았다.

## 변경된 동작

### 1. 명시적으로 충돌하는 시험의 표 연결을 차단

`rag/source_study_scope.py`에서 원문 참조 문장·표 캡션·표 본문에 인쇄된 등록 시험 ID와 상속 제목을 비교한다. 문서·버전·제품이 다르거나 명시된 시험 ID 집합이 양립하지 않으면 연결된 표 후보를 공급하지 않는다. 출처 문장의 정확한 시험 ID와 표 자체의 명시적 ID를 상속된 제목보다 우선한다. 번호가 같다는 이유만으로 충돌을 무시하지 않는다.

시험 Part 1과 Part 2는 구분한다. 시험 전체와 해당 Part의 관계는 허용하되, 다른 Part끼리는 같은 시험으로 축약하지 않는다. 여러 시험을 명시한 개요/비교는 단일 시험이라고 가정하지 않는다. 시험 ID를 알 수 없는 경우를 자동으로 정확하다고 인증하지 않는다.

기존 `BudgetedEvidence.linked_candidates()` 경로에 적용해 저장된 색인도 다시 쓰지 않고 연결 단계에서 차단한다. 원문에 잘못 인쇄된 Table 번호는 교정하거나 대체하지 않는다.

### 2. 본문·캡션과 충돌하는 상속 제목을 원문 증거로 공급하지 않음

실제 본문/캡션의 명시적 시험 ID가 상속 제목과 충돌하면, 요청 시점의 복사본에서 충돌하는 시험 제목과 그 아래의 상속 구조를 제거한다. 상위의 비시험 절 제목은 유지할 수 있다. 원문 본문과 출처 범위는 바꾸지 않고 `study_context_conflict`에 미해결 상태를 기록한다.

이때 새 시험 제목을 추론해 만들어 붙이지 않는다. 충돌하는 제목은 `verified_study_key()`와 `study_identity()`에서도 사용하지 않으므로, 그 제목을 기준으로 다른 본문을 확장하지 않는다. 저장된 청크·헤더·벡터 자체는 불변이다.

### 3. 새로 공급한 시험 본문의 표 참조도 한 번 확인

기존에는 최초 검색 청크의 표 참조를 복원한 뒤 같은 시험의 본문을 추가했다. 새로 추가한 본문의 표 참조는 다시 따라가지 않아 Table 7이 빠질 수 있었다.

`same_study_context`로 추가한 본문에 대해서만 한 차례 더 연결을 확인한다. 새 표를 재귀적으로 계속 확장하지 않는다. 동일한 문서/버전·시험 충돌 검사, 검색 허용 ID, 중복 제거, 전체 입력·스키마 예산을 유지한다.

### 4. 새 청크 생성에서는 시험 경계 인식을 보강

새 구조 규칙 `sections-10`은 `Clinical Ps study 20190232`처럼 짧은 임상 조건 설명이 붙은 독립 제목도 처리한다. 한 문서·시험 번호·페이지를 특별 취급하지 않는다. 등록된 시험 ID가 있어야 하며, ID 뒤에 본문 문장이 붙거나 앞에 `from`, `was`, `reported` 등 산문 형태가 있으면 제목으로 승격하지 않는다.

이전 `sections-8`과 실험용 `sections-9` 동작을 지원한다. `sections-9`의 한 단계 번호 제목 규칙은 기본으로 채택하지 않았다. 기존 설정으로 빌드할 때도 해당 버전으로 source segment를 나누도록 명시해, 기존 버전의 재현 계약을 유지한다.

### 5. BMI의 제곱미터 단위를 정확히 정규화

두 선정 기준 주장이 제거된 직접 원인은 PDF의 `kg/m 2` 또는 `kg/m²for`를 수치 검증기가 `kg`으로 읽는 것이었다. 명시적으로 인쇄된 제곱미터 표기를 `kg/m2`로 정규화한다. 원문 인용은 바꾸지 않는다.

숫자·단위를 검사하는 규칙은 유지한다. 다른 값, mg로 바뀐 BMI, 체중 kg만 있는 출처, 잘못된 지수 `m3`·`m20`는 BMI 단위 근거로 인정하지 않는다.
