# 신규 H 전처리·청킹·임베딩 완료 보고서

기존 승인 92문서, PDF 원문 4,102쪽 및 HTML DOM 미리보기 99쪽을 새 폴더에서 처리했습니다. 이전 코드·원문·DB·운영 인덱스와 서비스 포인터는 보존했습니다.

## 기능별 구성

1. 원문/메타데이터: 기존 catalog 및 승인 목록, 원본 HTML DOM·검증된 CMap PDF 파생본. 원본 문서 ID/버전/SHA, 제품·기관·유형·날짜·검색/평가 정책을 보존합니다.
2. 기본 추출: Heron 레이아웃, PDF 텍스트층 또는 RapidOCR/PP-OCRv6, TableFormer accurate. `ra_prep`은 별도 운영 보정 코드로, OCR 재판독·표 복원·머리말·절·발화자·연구 ID 규칙을 적용합니다.
3. 독립 누락 점검: PP-DocLayoutV3 + 닫힌 테두리 규칙. 원래 picture와 chart 증거를 보존하며 잘못 승격된 표는 후보로 분리합니다.
4. 선별 전사: PaddleOCR-VL-1.6-0.9B, 표 `table` 또는 의심 기호 `ocr` 작업. 총 949회, 채택 898회, 거절 51회. Qwen·그림 의미 설명·곡선 수치 생성은 없습니다.
5. 청킹: 기존 `preprocessed-chunks-13-closed-row-blocks`. 목표 768 / 최대 1024 / 표·그림 최대 2048, overlap 96. 절·연구 경계와 표 행 묶음, 캡션·각주, 원문 범위를 유지합니다.
6. 임베딩: 기존 BGE-M3 1024차원 정규화 dense cosine. 총 11,536벡터, 잘린 입력 0건. 완전히 같은 임베딩 입력만 기존 벡터를 재사용합니다.

## 오류 수정과 확인

- 각주 `$^{a}$`를 라벨 단어에 붙여 표 후보를 거절하던 검증 오류를 수정했습니다. 추출된 원문 표기를 바꾸거나 90% 라벨 보존 기준을 낮추지 않았습니다.
- 의심 특수기호는 원문 셀 crop을 다시 읽습니다. 기호 밖 문구와 V158 등의 표기를 보존하는 후보만 채택합니다. 자동 치환으로 정답을 주입하지 않습니다.
- 회전 PDF의 화면 좌표와 원문 좌표를 변환하며, 모든 bbox·원본/파생본 SHA·청크 표현 범위를 검사했습니다.
- 원본 메타데이터 불일치 0건, 92문서 모두 인덱스 연결, 보호한 기존 파일 189개 변경 없음, 벡터 정규화 및 ID 연결 검사 통과.
- 검토 필요 unit 728개는 원문/후보/거절 이유와 함께 보존하고 검색 적격성과 구분했습니다.

## 성능과 한계

기본 Docling 추출 누적 246.6분, BGE 임베딩 0.2분입니다. 단계별 실제 시간은 `stage_timings.json`, 모델 로딩/전사 시간은 각 `*_runtime.json`에 있습니다. 중단 후 재개 시간은 벽시계 총시간과 구분합니다.

전체 4,160쪽의 의미 정확도를 수치로 주장하지 않습니다. 기존 15쪽 개발 표본의 H 실험은 88/90 셀, 32/34 구절, 표 18/18·그림 4/4였고 독립 검토 전입니다. 이번 전체 처리는 출처·구조·메타데이터·범위·벡터 무결성을 확인한 결과입니다. `metadata_and_integrity_audit.json`과 `candidate_decisions.json`에서 근거를 확인할 수 있습니다.

## 사용 위치

- 새 청크·벡터: `candidate/`
- 기존 읽기/검색 도구 호환 릴리스: `release/`

서비스 전환은 수행하지 않았습니다. 새 릴리스 경로를 지정하면 기존 검색·원문 검토 도구로 사용할 수 있습니다.

## DOM·좌표 보완 적용

HTML10문서는 원본 DOM의 1,022개 단위를 직접 보존했습니다. HTML의 PDF는 새 DOM 기반 미리보기이며 원본 페이지 번호가 아닙니다. DOM node path/start/end와 원본 SHA를 참조에 기록했습니다. 원래 catalog metadata는 변경하지 않았습니다.

독립 문자 좌표로 복구한 항목 1개, 미해결 작은 문자 좌표 경고 16개입니다. 경고에는 원문·원시 block·페이지 미리보기를 남겼으며 이 경고 때문에 같은 페이지의 정상 본문을 제외하지 않습니다. 전체 의미 정확도가 검증됐다는 뜻은 아닙니다.

임베딩 재사용 원본은 이전 v1의 완료 candidate입니다. 재사용 11,277개, 새 계산 259개이며 동일한 header+text만 재사용했습니다. 새 run/candidate/release를 만들고 기존 운영 서비스 포인터는 유지했습니다.

원본 HTML의 독립 텍스트 노드 1,835개도 추출 표현과 대조했으며 미포함 노드 0개입니다. HTML 청크의 도구 출처는 실제 HTMLParser/Story로 정정했고, 정정 전후 모든 임베딩 입력·청크 ID·벡터 파일이 동일함을 확인했습니다. 이전 v1 완료 벡터와 기존 운영 보호 파일 189개는 변경하지 않았습니다.
