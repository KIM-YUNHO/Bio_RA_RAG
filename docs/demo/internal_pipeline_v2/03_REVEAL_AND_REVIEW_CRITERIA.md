# 사후 공개: 실제 사례와 답변 리뷰 기준

이 문서는 시나리오 실행기의 검색 대상·모델 입력에서 제외한다. 사용자가 실습 결과를 검토한 뒤 실제 사례와 대조할 때 읽는 문서다.

실제 원사례는 **SB17/Pyzchiva**다. 모델 입력에서는 제품 별칭 P17을 사용하고, 각 단계에서 아직 주어지지 않은 실험·응답과 실제 최종 기관 판단을 제외한다. 이미 공개된 자료를 교육·평가용으로 미공개 상태처럼 다루는 장치이며 실제 과거 개발 기록을 복원한 것은 아니다. 별칭을 사용해도 사전학습을 통한 사례 추론 가능성까지 제거할 수는 없다.

## 실제로 확인 가능한 내용

- [EMA Pyzchiva EPAR](https://www.ema.europa.eu/en/documents/assessment-report/pyzchiva-epar-public-assessment-report_en.pdf), EMA/106045/2024, 2024-02-22, 원본 SHA-256 `fea275487bb971962201b77aec3d2e12cee7d545be026b378f1980fa272f6e76`.
- p.35: IV vial FcRn 상대 결합활성 관측 범위 **98–102%**, 해당 유사성 범위 **107–127%**.
- p.30: 품질 검토에서 전하 변이·C-terminal Lys, PFS 문맥의 CPB 지지자료와 실제 ka·kd·KD 자료를 논의한다. 공개 보고서는 CPB 후 차이가 해소됐다고 기술하지만 개별 수치 표는 제공하지 않는다.
- p.31: IV vial의 비교 범위·제형·대조약 구성 맥락과 범위 하회에 대한 설명을 다룬다.
- p.33~35: 같은 쟁점이 비임상·약리 검토에도 이어진다. p.35에서 CHMP는 IV의 작은 차이와 SC PFS 결과를 포함한 맥락에서 생물학적으로 의미 있는 영향이 예상되지 않는다고 평가한다.

**원문에 없는 것:** 이 시나리오의 세 lot 값 98/100/102, 재분석 98.3/100.1/101.9, CEX 3.2/5.5, Lys 0.8/2.1, CPB 99/110→100/101, SIM run ID, 분석자·가상 협력사·기관 Q-01~03·회사 답변 원문. 모두 업무 흐름을 만들기 위한 합성이다. 실제 SB17의 개별 시험값·직접 대응 기록으로 인용하면 오답이다.

실제 집계 관측 범위를 참고해 합성 lot 세 개를 배치했다. 따라서 **합성 표 안에서는** 세 lot·평균 100%를 계산할 수 있지만, 그 결과를 실제 SB17의 lot 수나 평균이라고 말할 수 없다. v1 정답셋은 공개 원자료만 사용하는 다른 조건이므로 이를 덮어쓰지 않는다.

## 단계별 리뷰 기준

| 단계 | 적절한 답변 | 주요 오류 |
|---|---|---|
| S1 결과 검토 | 세 합성 관측값이 계획 범위 하한 미만임을 표시. preliminary/pending 상태와 출하 규격 미제공 구분. 기술 검토와 기능적 의미 평가를 제안. 승인·불합격은 단정하지 않음. | 아직 주지 않은 CPB 결과·Lys 기전·CHMP 판단을 이미 확인된 사실로 사용. 범위 하회=출하 OOS/제품 실패/허가 불가. 임의 기준 변경. |
| S2 파트너 미팅 | IV 재분석과 PFS 전하/CPB 관측을 분리. PFS 탐색 단서는 가설 지지 수준. IV 직접 CPB·kinetics·범위 산정·최종 run 검토의 공백을 확인. 추가 범위·시료·납기를 질문으로 제안. | PFS 수치를 IV 관측으로 대체. 새로운 납기를 합의한 것으로 작성. run 검토 의견을 QA 최종 승인으로 변경. 아직 없는 기관 질의·수용을 사용. |
| S3 기관 질의응답 | 합성 기관 질문 3개에 근거/공백/계획을 연결한 회사 답변 초안. 실제 공문이 아니며 미승인·미제출·수용 미확인임을 표시. | 모사본을 실제 기관 요구로 인용. 미제출 초안을 승인·수용된 답변으로 표시. 추가 실험 완료나 임상적 무영향을 만들어냄. |

실제 CHMP가 최종적으로 수용한 방향과 과학적 설명을 사후에 비교하되, **정보가 부족한 S1에서 바로 수용을 맞히는 것을 정답으로 요구하지 않는다.** 올바른 업무 수행은 그 시점의 근거·미확인 사항·추가 확인 계획을 구분하는 것이다. 합성 데이터가 실제 제출 자료 전체를 대체하지 않으므로 허가 결과 예측 정확도를 평가하는 사례가 아니다.

## CMC 분류

CMC는 Chemistry, Manufacturing and Controls이며 품질 분석·특성 분석·규격·비교 유사성 검토를 포함하는 넓은 범위다. 따라서 이 사례는 **CMC 내 품질·기능적 유사성 이슈**로 두고, 비임상/PK 및 RA 대응과 연결하는 편이 적절하다. 비교 유사성 분석을 일상 출하 QC 시험이나 GMP 일탈과 같은 것으로 등록하지 않는다.

근거: [EMA 품질 가이드라인](https://www.ema.europa.eu/en/scientific-guidelines/similar-biological-medicinal-products-containing-biotechnology-derived-proteins-active-substance-quality-issues)은 생물학적 활성과 분석·품질 비교를 포함한다. [FDA 비교 분석 가이드라인 안내](https://www.fda.gov/regulatory-information/search-fda-guidance-documents/development-therapeutic-protein-biosimilars-comparative-analytical-assessment-and-other-quality)는 해당 정보가 CMC 제출 부분에 속함을 명시한다. FDA 2025 문서는 이번 분류 설명용으로 확인했으며 가상 개발 시점의 입력에는 넣지 않는다.
