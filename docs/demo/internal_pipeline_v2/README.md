# SB17 사례를 미공개 개발 시점으로 돌린 업무 시뮬레이션

> **이어서 진행한 최신 결과:** [v3 보완·재실행 리뷰](../internal_pipeline_v3/01_REVIEW_WALKTHROUGH.md). 이 v2의 입력·답변·검토 기록은 비교 기준으로 보존한다.

사용자의 2026-10-18 설명을 반영한 v2다. 실제 SB17에서 발표한 결과를 아직 모르는 것으로 두고, 해당 쟁점에서 실제 회사가 주고받을 법한 **합성 내부 시험자료·분석 코멘트·협력사 회신·기관 질의응답 초안**을 순차 공급한다.

**처음에는 [진행 결과와 리뷰 한 편](01_REVIEW_WALKTHROUGH.md)만 읽으면 된다.** 앱이나 코드부터 따라갈 필요는 없다.

| 파일 | 용도 |
|---|---|
| [01 리뷰](01_REVIEW_WALKTHROUGH.md) | 무엇을 넣었고, 모델이 무엇을 했고, 어떤 문제가 있었는지 순서대로 설명 |
| [02 내부 자료](02_INTERNAL_DOCUMENTS.json) | 실행에 사용한 11개 정보 단위와 단계별 사용자 질문. 수치·코멘트·상태가 들어 있는 원 입력 |
| [03 실제 결론·리뷰 기준](03_REVEAL_AND_REVIEW_CRITERIA.md) | 사용자/리뷰어만 보는 실제 SB17 원사례와 단계별 적절한 답변 기준. 모델 입력 제외 |
| [04 자동 생성 원문](04_GENERATED_DRAFTS.md) | 실제 모델 답변 3개. 리뷰에서 지적한 오류를 포함한 원문 보존 |
| [05 실행·리뷰 기록](05_RUN_REVIEW.json) | 호출 수·선택한 출처·검사 결과·검토에서 찾은 오류 |

v1은 공개자료를 정리한 메모 기능 데모로 남겨둔다. v2는 **결론을 모르는 상태의 업무 진행**을 확인하는 별도 실행이다. 실제 기업 원자료나 역사적 질의응답을 복구한 것으로 표현하지 않는다. 원문에 없는 개별 수치는 합성이라고 명시한다.

이번에는 저장 메모를 읽는 격리 실행기로 실제 답변 3개를 생성했다. 운영 앱의 전체 pgvector/BGE-M3 검색에 붙인 상태는 아니며 v1의 12개 정답셋 전체를 실행한 것도 아니다. 실제 최종 심사 결과를 예측하는 정확도 점수는 산출하지 않는다.
