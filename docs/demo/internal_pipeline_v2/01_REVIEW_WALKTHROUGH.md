# SB17 FcRn 시나리오: 한 번 진행해 본 결과와 리뷰

> 중단 지점 이후의 보완과 재실행은 [최신 v3 리뷰](../internal_pipeline_v3/01_REVIEW_WALKTHROUGH.md)에 이어서 정리했다. 아래는 첫 실행 당시 기록이다.

2026-10-18 · 첫 업무 시뮬레이션 실행. **이 문서를 위에서 아래로 읽으면 된다.** 각 단계의 내부 자료를 확인하고 그때 가능한 판단을 읽은 다음, 마지막에 실제 공개 사례와 비교한다.

이번의 핵심 질문은 “이미 공개된 SB17 이야기를 잘 요약하는가?”에서 **“결론이 아직 없는 개발 담당자에게, 내부 시험자료와 응답을 근거로 다음 업무를 도와주는가?”**로 바꿨다. 이전 앱 데모는 CHMP 판단까지 처음부터 보여줬으므로 이 목적에 맞지 않았다.

## 이 이슈를 CMC로 봐도 되는가

**그렇다. ‘CMC 중 품질·기능적 유사성 비교에서 발견한 이슈’로 두는 것이 적절하다.** CMC는 제조만 뜻하지 않고 품질의 분석·특성·관리도 포함한다. FcRn은 생물학적 기능 관련 비교이며, 발견한 차이의 비임상·PK 의미를 함께 검토하게 된다.

| 관점 | 이 시나리오에서 하는 일 |
|---|---|
| 품질·분석 개발 / CMC | IV FcRn 차이, 분석법·대조약·비교 범위, 전하 변이·기능 연결 확인 |
| 비임상·PK | 그 차이가 생물학적 거동과 어떤 관련이 있는지 평가 |
| RA | 확인한 근거·한계·계획을 묶어 기관 질의·회사 답변 초안 준비 |
| 출하 QC / QA | 별도의 규격·품질 절차 맥락. 이번의 비교 범위 하회만으로 출하 OOS나 제품 불합격이라고 기록하지 않음 |

실제 [EMA 품질 가이드라인](https://www.ema.europa.eu/en/scientific-guidelines/similar-biological-medicinal-products-containing-biotechnology-derived-proteins-active-substance-quality-issues)은 생물학적 활성과 분석·품질 비교를 포함한다. 실제 SB17 EPAR도 품질 절(p.30~31)과 비임상 절(p.33~35)에서 이 쟁점을 다룬다. [FDA 안내](https://www.fda.gov/regulatory-information/search-fda-guidance-documents/development-therapeutic-protein-biosimilars-comparative-analytical-assessment-and-other-quality)에서도 비교 분석 정보가 CMC 제출 부분에 속한다고 설명한다.

따라서 저장할 때는 `영역: CMC`, `활동: 품질·기능적 유사성 분석`, `쟁점: IV FcRn 범위 하회`, `연결 업무: 비임상/PK·RA`, `현재 시점: S1/S2/S3`를 분리하는 편이 좋다. CMC가 끝난 뒤에만 다른 부서가 일을 시작하는 단일 순서로 볼 필요는 없다.

## 실제 자료에서 가져온 부분과 합성한 부분

실제 SB17 공개 관측 범위 **98–102%**와 그 사례의 비교 범위 **107–127%**, 전하 변이·C-terminal Lys·CPB 관련 설명의 방향을 사례 설계에 사용했다. 최종 심사 결론은 모델에게 주지 않았다.

내부 자료는 다음처럼 합성했다.

| 합성한 자료 | 예 |
|---|---|
| 실험 결과표 | 가상 lot 3개와 run ID, 잠정 결과·재분석 값, 시험 검토 상태 |
| 지지 실험 | 가상 PFS의 전하 변이·Lys 분석 수치와 CPB 전후 FcRn 표 |
| 분석자 코멘트 | 원인 미확인, 계산·run 확인 요청, 기준 완화/임의 무효화 보류 |
| 협력사 응답 | 실시한 시험과 미실시 시험, 추가 범위·시료·납기의 미합의 |
| 내부·규제 대응 | CMC/RA 응답, 연습용 기관 질문 3개, 미승인·미제출 회사 답변 초안 |

**개별 수치는 실제 SB17의 숨겨진 원자료를 복원한 값이 아니다.** 업무를 시험하기 위해 만든 숫자다. 모델에는 P17이라는 별칭을 사용했고 S1→S2→S3를 실제 SB17 개발 날짜로 표시하지 않았다. 실제 기업의 모든 연구시험에 QA 서명이 필수라는 규칙을 만든 것도 아니다. 이번 합성 업무에서 주어진 검토 상태를 따르게 했다.

## 1장: 결과를 처음 받은 분석 담당자 — S1

**당신은 IV 품질 비교 결과를 처음 받은 담당자다.** 아직 재분석·CPB 결과·기관 의견이 없다.

| 가상 lot | 첫 FcRn 상대 결합활성 요약값 |
|---|---:|
| SIM-IV-A | 98.0% |
| SIM-IV-B | 100.0% |
| SIM-IV-C | 102.0% |

합성 계획서의 비교 범위는 107–127%다. 결과는 `preliminary`, run 유효성은 `pending`이다. 표준품·대조군·계산 검토와 분석책임자 확인이 진행 중이다. 반복 측정 원자료, 시험법 상세 검증, 범위 산정 첨부는 미제공이다. [입력 U01~U05]

**실제로 넣은 질문:** “FcRn 결과가 98–102%로 나왔다. 내부 비교 범위 107–127%에 통과할 수준인가? 현재 결과·시험 유효성·판단 가능한 범위를 구분하고 확인 자료와 다음 조치를 정리해 달라.”

**모델이 한 일:** 세 요약값이 비교 범위 하한 미만임을 표시했고, 이것이 출하 규격이나 보편적 허가 합격선이 아니라고 구분했다. 시험 유효성·제품 불합격·기관 수용·임상적 영향은 판단할 수 없다고 했다. 원자료·정규화·대조군·시험법·범위 산정 근거 확인과 독립 재분석을 제안했다.

**리뷰:** 현재 자료에서 가능한 판단 범위는 적절했다. 아직 없는 CPB 결과나 실제 CHMP 판단을 가져오지 않았다. 다만 문서마다 원인 후보와 확인 요청을 반복해 답변이 길어졌다. 담당자가 볼 최종 형태는 다음 3줄이면 충분하다.

> 현재 세 합성 값은 이번 IV 비교 범위보다 낮다. 아직 검토 중인 결과이므로 제품/허가 결론과 구별한다. 먼저 run·계산·대조약 범위의 근거를 확인하고, 차이가 유지되면 구조·기능 관련성 평가를 준비한다.

이 3줄은 **리뷰어가 정리한 문구**이며 모델 원문은 04번 문서에 그대로 보존했다.

## 2장: 추가 결과를 받고 협력사 미팅을 준비 — S2

**며칠 뒤 내부 재분석과 협력사 회신이 추가됐다.** 아래도 모두 합성 데이터다.

| 추가된 자료 | 현재 읽을 수 있는 내용 |
|---|---|
| IV 재분석 | 같은 lot의 98.3 / 100.1 / 101.9%. 같은 방향의 차이가 반복됨 |
| 분석자 검토 응답 | 특정 계산 오류·무효화 사유를 아직 찾지 못했다는 담당자 의견. 상세 검증·최종 서명은 미제공 |
| PFS 전하 변이 | 가상 시료 한 쌍에서 CEX basic fraction 3.2 / 5.5%, Lys 관련 분석 0.8 / 2.1% |
| PFS CPB 탐색 | 처리 전 P17/기준약 99 / 110%, 처리 후 100 / 101%. 한 쌍의 탐색 관측 |
| 아직 없는 것 | IV CPB 직접 결과, ka·kd·KD 표, 추가 IV CPB 범위·시료·납기 합의 |

숫자의 각 %는 서로 다른 지표이므로 더하지 않는다. PFS CPB 차이 감소는 가설을 지지할 단서이지 IV 직접 관측이나 임상적 무영향의 입증이 아니다. [입력 U06~U09]

**실제로 넣은 질문:** “한빛분석 미팅용으로 IV 재분석과 PFS 전하 변이·CPB 회신을 대조해 코멘트와 질문을 준비해 달라. 이미 한 일, 미확인 결과, 새로 합의할 범위·일정을 나눠 달라.”

**모델이 한 일:** IV 재분석 수치와 PFS 탐색 수치를 별도 안건으로 정리했다. 원자료·대조군·CPB 조건·kinetics·IV 확인·추가 일정에 대한 질문을 만들었다.

**리뷰에서 찾은 오류:** 모델은 초기 요청 U04를 근거로 “현재 협력사 수락이나 납기 합의는 없다”고 넓게 썼다. S2에는 이미 IV 재분석 및 PFS 결과 회신이 있다. **미합의인 것은 ‘추가 IV CPB’ 범위와 납기다.** 과거의 요청 상태를 현재 전체 업무 상태로 옮긴 오류다.

또 “IV와 PFS 결과를 직접 연결해 해석할 수 없다”는 문구는 지나치게 넓다. PFS 결과를 IV의 직접 측정처럼 쓰면 안 되지만, 차이를 설명하기 위한 간접 지지자료로 검토할 여지는 있다. 분석자가 오류를 발견하지 못했다는 회신도 독립 검증 사실로 승격하지 말고 발언 주체를 붙여야 한다.

**리뷰 후 미팅 메모 예:**

> IV 재분석과 PFS 탐색 결과는 회신받았다. IV의 낮은 결과는 반복됐고 PFS CPB에서는 차이 감소 단서가 보인다. IV 직접 CPB와 kinetics 자료는 현재 없다. 미팅에서는 실시한 시험의 근거 파일을 확인하고, 추가 IV CPB의 목적·시료·담당·납기를 새로 합의한다. 현재 QA/RA 결론이나 기관 수용은 없다.

이 문구 역시 리뷰어 수정안이며 전송·승인하지 않았다. 모델 출력에 출처 ID가 모두 있어도 최신 상태·적용 범위가 틀릴 수 있음을 확인한 단계다.

## 3장: 기관 질의응답을 연습 — S3

**연습용 기관 질문과 내부 답변 초안이 추가됐다.** 실제 기관에서 온 문서가 아니다.

- Q-01: IV FcRn 범위 하회와 대조약 lot·범위 설정 근거를 설명하라.
- Q-02: PFS 전하 변이·CPB 자료를 IV 설명에 쓰는 근거와 한계를 제시하라.
- Q-03: FcRn 차이의 생물학적·PK 관련성과 추가 자료 계획을 설명하라.

**실제로 넣은 질문:** “Q-01~03 회사 답변 초안을 작성하고, 근거·공백·내부 확인 질문을 연결해 달라. 실제 기관 발신/회신인지, 승인·제출·수용 상태도 표시해 달라.”

**모델이 한 일:** 문항마다 현재 관측, 부족한 자료, 내부 확인 질문을 묶었다. 질문은 합성이고 회사 답변은 미승인·미제출이라고 표시했다. 실제 기관의 수용이나 임상적 무영향을 꾸며내지 않았다.

**리뷰:** 문항별 근거·공백 연결은 유용했다. 다만 S2와 같은 초기 협력사 상태 오류가 마지막 상태 표시에 반복됐고, 마지막에 `승인·제출·수용 여부: .`라는 불완전한 문구가 남았다. 승인/제출/수용은 “미승인 / 미제출 / 실제 기관 판단 없음”처럼 구조화된 상태에서 출력해야 한다. 현재 자동 답변을 그대로 기관용 문서로 쓸 수준은 아니다.

## 4장: 실제 SB17 결과를 사후 공개해서 비교

이제 [실제 원사례와 리뷰 기준](03_REVEAL_AND_REVIEW_CRITERIA.md)을 연다. 원본의 IV 관측 범위는 98–102%, 비교 범위는 107–127%였고, 품질·기능·제형 관련 자료를 종합해 CHMP는 이 사례에서 생물학적으로 의미 있는 영향이 예상되지 않는다고 평가했다.

이번 실습이 그 결론을 미리 맞히도록 요구한 것은 아니다. **S1의 불완전한 정보로 최종 수용을 단정하지 않고, 추가 자료가 들어올 때 설명을 갱신하는지가 업무상 더 중요한 평가 기준**이다. 합성 시나리오의 자료 묶음은 실제 제출 자료 전체가 아니므로 허가 결과 예측 정확도로 점수화하지 않았다.

## 이 결과를 바탕으로 메모 구조에서 바꿀 부분

첫 구현의 유형·대상·상태 분리는 유효했지만, **관측/의견 분리와 업무 상태 갱신을 더 명확하게 저장해야 한다.**

1. **실험값과 검토자 발언을 다른 항목으로 나눈다.** 예를 들어 U06 안의 재분석 수치와 “계산 오류를 찾지 못했다”는 김분석의 의견을 분리하고 각각 주체·근거를 붙인다.
2. **요청→수락→실행→결과 회신→검토를 시험 범위별로 연결한다.** IV 재분석, PFS CPB, 추가 IV CPB는 서로 다른 업무다. 한 가지 ‘미완료’ 상태로 묶으면 이번 오류가 반복된다.
3. **담당자 의견의 현재성·적용 범위를 함께 조회한다.** 날짜가 늦은 문서라고 모든 예전 기록을 대체하는 것은 아니다. 무엇에 대한 새 응답인지 확인해야 한다.
4. **출력의 승인·제출·수용 상태를 명시 필드로 만든다.** 빈 문자열 대신 `초안 / 미제출 / 기관 판단 없음`처럼 표현한다.
5. **실무 출력은 판단·근거·공백·다음 행동 4칸으로 줄인다.** 현재 답변은 반복이 많아서 읽는 사람이 따라가기 어렵다.

이 다섯 가지는 이번 실행에서 드러난 후속 보완사항이다. 운영 코드에 모두 구현한 것으로 표시하지 않는다. 지금 사용자가 먼저 볼 것은 위 세 단계에서 **어떤 자료가 언제 생기고, 그때 담당자가 어떤 판단·응답을 해야 하는지**다. 전체 자동 생성 원문은 [04번](04_GENERATED_DRAFTS.md), 과학적 원천과 정답 기준은 [03번](03_REVEAL_AND_REVIEW_CRITERIA.md)에 있다.
