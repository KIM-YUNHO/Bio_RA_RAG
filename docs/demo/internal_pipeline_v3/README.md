# 미공개 개발 시점 시나리오 보완판

> 후속: [v4](../internal_pipeline_v4/README.md)에서 이 흐름을 앱 기능으로 옮기고, 문서 본문에 해석 문장을 넣지 않은 새 시나리오로 실행·보완했다.

**[이번 진행 결과와 전후 비교 리뷰](01_REVIEW_WALKTHROUGH.md)부터 읽으면 된다.**

v2에서 발견한 과거 요청 상태의 오용, 실험 결과와 의견의 혼합, 불완전한 승인·제출 표시를 보완한 실행이다. SB17의 공개 집계에서 출발한 합성 실험·업무 자료를 사용하며 실제 최종 기관 판단은 계속 모델 문맥에서 제외한다.

- [02 원 입력](02_INTERNAL_DOCUMENTS.json): 관측·의견·작업 회신을 분리한 16개 항목. 공급 시점·발언 주체·업무 이벤트 포함.
- [03 실제 결론과 리뷰 기준](../internal_pipeline_v2/03_REVEAL_AND_REVIEW_CRITERIA.md): 사후 대조용. 모델 입력에서 제외.
- [04 실제 생성 답변](04_GENERATED_DRAFTS.md): 최종 재실행의 자동 출력과 원문 이벤트에서 산출한 상태 표.
- [05 실행·검토 기록](05_RUN_REVIEW.json): 이전 실행 대비 항목 수, 호출 수, 자동 검사와 수동 검토의 구분.

이전 [v2 리뷰](../internal_pipeline_v2/01_REVIEW_WALKTHROUGH.md)와 자동 출력은 보존했다. 이번 결과도 운영 앱 전체 검색에 통합한 성능이나 허가 결과 예측 정확도를 의미하지 않는다.
