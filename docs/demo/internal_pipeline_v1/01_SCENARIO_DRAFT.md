# 실제 SB17 자료로 다시 구성한 내부 검토 시나리오

버전: 0.1 · 작성: 2026-10-18 KST · 상태: 사람이 읽고 검토할 초안

이 초안은 **실제 공개자료를 재구성한 내부 업무용 합성문서**다. 실험 결과와 규제기관 평가의 출처는 EMA의 Pyzchiva(SB17) 공개 심사보고서다. 실제 회사의 내부 실험노트·회의록·계약은 확보하지 않았다. 내부 의견, 가상 협력사, 미팅·업무 일정만 교육용으로 만들었다.

실제 수치는 실제 제품 **SB17/Pyzchiva**의 결과로 표시한다. 가상의 자사 후보가 측정한 값으로 바꾸지 않는다. SB17의 공개 결과를 가상의 개발팀이 검토하는 사례 재연이며, 실제 SB17 개발팀의 업무 기록을 복원한 것이 아니다. 현재 서비스에 적재하지 않았다.

## 핵심 이야기: 범위 밖이라는 사실과 최종 평가 사이

EMA 보고서에서 Pyzchiva의 **IV vial FcRn 상대 결합활성은 98~102%**, 이 사례에서 설정한 유사성 범위는 **107~127%**로 기재된다. 따라서 이 항목의 관측 범위는 제시된 유사성 범위보다 낮다. 이것만 보고 “제품 전체 실패” 또는 “다른 항목이 양호하므로 통과”라고 답하면 중요한 검토가 빠진다.

같은 보고서는 전하 변이와 C-terminal Lys 차이, 관련 기능 분석, carboxypeptidase B(CPB) 처리 자료, FcRn 결합 관련 실제 ka·kd·KD 자료를 함께 다룬다. CHMP는 IV vial의 차이가 작고 SC PFS에서는 차이가 관찰되지 않았다는 맥락에서 생물학적으로 의미 있는 영향이 예상되지 않는다고 평가했다. 이것은 **SB17 자료를 평가한 실제 기관 판단**이며, 숫자만 비슷한 다른 후보에 자동으로 적용할 수 있는 허용 규칙이 아니다.

사용자는 이런 상황에서 “FcRn이 범위 밖인데 무엇을 더 봐야 하나”, “분석 파트너 미팅에서 어떤 부분에 코멘트할까”, “기관에 무엇을 물을까”를 요청한다. RAG는 관측·평가기준·지지자료·기관 판단을 연결하고, 내부 담당자의 제안과 구분해 초안을 만든다.

## 실제 사실과 합성 업무를 구분하는 표

| 구분 | 이번 초안에서 쓰는 내용 |
|---|---|
| 실제 제품·비교약 | SB17/Pyzchiva, EU-Stelara |
| 실제 관측 | IV vial FcRn 상대 결합활성 98~102% |
| 실제 사례의 유사성 범위 | FcRn 107~127%; 보편적 합격선 또는 출하 규격 아님 |
| 실제 시험 맥락 | 130 mg IV vial, 45 mg SC PFS, 제형별 EU-Stelara와 비교 |
| 실제 기능시험 | IL-23/IL-12 중화, IL-23/IL-12 ELISA 결합, FcRn 등 |
| 실제 지지자료·해석 | 전하 변이·Lys 차이·CPB 처리·결합 관련 ka/kd/KD 자료에 대한 보고서 서술 |

| 미공개이므로 채우지 않는 것 | 개별 lot 값·실제 lot ID·시험 run ID·SOP 버전·시험일·내부 승인일·개별 ka/kd/KD 수치 |
| 합성 역할·회사 | 가상 검토팀의 CMC 최연구·RA 한규제·검토자 박검토, 가상 분석 파트너 가온분석·제조자료 파트너 누리바이오 |
| 합성 업무 | 공개자료 발췌·검토 의견·자료 요청·미팅 코멘트·일정 합의·기관 질문 초안 |

가온분석·누리바이오는 데모에서 만든 회사명이며 실제 SB17 개발의 CRO/CDMO라는 뜻이 아니다. 자료 요청은 역할 연습을 위한 것이며 실제 비공개 자료를 확보하거나 생성했다는 뜻이 아니다.

## 세 단계로 자료를 보여주는 방식

아래 날짜는 **2026년에 진행하는 모의 검토 세션의 기준일**이다. 2024년 공개 심사자료의 실제 생산·제출·승인 연혁이 아니다. 같은 보고서 중 어느 절을 검토자에게 공급했는지 바꿔, 필요한 문맥을 추가로 찾는 행동을 확인한다. 날짜를 문헌 검색의 실제 공개일 필터로 사용하지 않는다.

| 모의 세션 | 공급하는 재구성 문서 | 검토할 점 |
|---|---|---|
| T1: 2026-08-19 18:00 KST | REPLAY-D01~03, D06 | FcRn 수치와 제형별 비교 범위를 확인한다. D03에는 p.31의 차이가 설명됐다는 요약 평가가 있으나, p.30의 상세 지지자료와 p.35~36 최종 논의·결론은 아직 공급하지 않은 상태다 |
| T2: 2026-08-25 18:00 KST | T1 + REPLAY-D04, D07~08 | Lys/CPB 등 지지자료의 존재와 한계를 확인하고 협력사 질문·일정을 준비한다 |
| T3: 2026-09-07 18:00 KST | REPLAY-D01~09 전체 | 실제 CHMP 평가를 확인한 뒤 내부 의견과 구분하고 기관 질문 초안을 고친다 |

모든 원문은 같은 실제 공개보고서를 참고한다. T1·T2에 p.35~36의 최종 논의·비임상 결론 발췌문을 주지 않은 것은 데모용 공급 제한이며, 그 당시 실제 기관 평가가 없었다는 뜻이 아니다. p.31의 요약 평가는 T1부터 D03에 있다. 이 세션 설명과 예상 행동은 향후 검색 원문에서 분리한다.

## 사용자가 읽어볼 세 요청

> **결과 검토:** SB17 IV vial의 FcRn 결합활성이 98~102%인데 보고서의 범위는 107~127%야. 이 차이를 어떻게 검토했는지 정리하고, 다른 개발품에서도 참고하려면 확인할 조건을 알려줘.

좋은 초안은 “수치상 해당 사례의 범위 밖”을 먼저 밝히고, 제형·시험법·대조약 lot 구성·지지자료·기관의 사례 판단을 연결한다. SB17 결론을 가상 자사 후보의 합격으로 바꾸지 않는다. 개별 lot 값과 상세 시험법이 없으면 없다고 표시한다.

> **미팅 준비:** 9월 8일 가온분석 미팅에 쓸 코멘트를 만들어줘. FcRn·전하 변이·CPB 자료에서 확인할 내용을 정리하고, 약속한 제출일과 합의된 날짜를 구분해줘. 외부 전달본은 공유 가능한 내용만 넣어줘.

합성 업무 문서의 이메일 목표와 양측 일정 합의를 구분한다. 실제 원문 인용은 공유 가능한 공개자료에 연결한다. 내부 공급업체 평가와 누리바이오 전용 요청은 가온분석 전달본에서 제외한다.

> **기관 질문:** 이 공개 사례를 참고해 우리가 다음 단계 개발품에서 FcRn 차이를 보였을 때 기관에 확인할 질문을 초안으로 만들어줘. 현재 가진 근거와 아직 없는 자사 자료를 분리해줘.

SB17의 실제 CHMP 의견은 참고 선례다. 가상 개발품의 관측 결과·제형·시험법·lot 구성은 아직 없으므로 질문에 임의의 자사 측정값을 넣지 않는다. 기관의 답변·사전 동의·새 기준은 만들지 않는다.

## 원문과 메모를 연결하는 단위

공통 연결 ID는 이 데모에서 붙인 **`CASE-SB17-FCRN`**이다. 실제 공개 연구번호가 아니다. 실험 ID·배치 ID·run ID를 새로 만들어 실제 원자료인 것처럼 기록하지 않는다.

| 문서 | 내용 | 정보 역할 |
|---|---|---|
| REPLAY-D01 | 실제 사례·제형·공개범위 | 사례 범위 |
| REPLAY-D02 | 실제 기능시험과 보고된 유사성 범위 | 시험 맥락·사례 기준 |
| REPLAY-D03 | 실제 IV FcRn 관측 범위와 제형 구분 | 관측·비교 |
| REPLAY-D04 | 전하 변이·CPB와 지지자료 | 근거·신청자 설명·보고서 검토 |
| REPLAY-D05 | 실제 CHMP 평가 | 기관 판단 |
| REPLAY-D06 | 가상 검토팀 의견 | 의견·제안 |
| REPLAY-D07 | 가상 파트너 업무 의뢰 | 요청·조건부 일정 |

자유서술 메모의 문장을 이 역할별 항목으로 연결하되 원 메모와 인용 구간을 보존한다. “98~102%”라는 관측, “Lys 차이와 관련 있다”는 원문 설명, “CPB 자료를 요청하자”는 내부 제안은 같은 종류의 사실이 아니다. 문서 전체를 한 태그로 묶는 것보다 이 구분이 후속 결과 검토·미팅·질문 작성에 직접 필요하다.
