# 시나리오 v5 — IV vial FcRn 이슈 대응 (RAG 가이드)

사내에서 이슈가 하나 생겼을 때, 공개 규제 문서 RAG가 해결 방향을 얼마나 잘 안내하는지 보는 시나리오다.

## 무엇을 보나

- **이슈:** P17(가명) 130 mg IV vial의 FcRn 상대 결합이 98.0–102.0%로, 계획서 유사성 범위(107–127%) 하한 미만이다. QA가 결과를 유효로 승인했고, SC PFS는 범위 안이다.
- **RAG 가이드:** 질문은 사람이 미리 쓰지 않는다. 진행은 다음 순서다.
  1. AI가 이슈와 사내 사실을 읽고 원인 가설과 검색 질문 4~5개를 만든다. 질문은 같은 시험 항목의 다른 제품 사례, 가설 특성별 확인 방법과 PK 판단, 지침 요구를 다룬다.
  2. 같은 성분 바이오시밀러의 공개 심사 자료와 지침을 검색한다.
  3. 1차 답변에서 새로 드러난 단서로 추가 질문 0~2개를 더 검색한다.
  4. AI가 인용된 답변을 다섯 칸으로 정리한다: 원인 규명 방향, 실험 설계, 기관 대응 논리, 예상 심사 질의, 다른 제품 사례.

  가설 질문은 이슈의 시험 항목(FcRn) 이름에 묶지 않고 그 특성 자체를 묻는다. 다른 제품에서는 같은 특성 차이가 다른 시험 항목과 함께 평가됐기 때문이다.
- **정답 대조(평가용):** 실제 사례인 SB17(Pyzchiva) EMA 공개 심사보고서의 해결과 비교한다. 비교하는 점은 다섯 가지다: C-말단 Lys로 설명, CPB 확인 시험, 범위 설정 맥락, PFS 결과, 영향 없음 결론.

## 정답이 새지 않게 한 장치

| 장치 | 내용 |
|---|---|
| 검색 제외 | 이슈의 `search.exclude_products`(SB17)를 뺀 제품만 검색한다. 답변이 SB17 문서를 인용하면 가이드는 실패로 끝난다. |
| 내부 문서 | 5건(계획서, IV·PFS 결과, QA 기록, 착수 메모)뿐이다. 원인 가설·CEX·CPB 자료는 넣지 않았다. |
| 정답 | `answer_key`는 화면 검토용이다. AI 입력에 들어가지 않는 것을 테스트로 확인한다(`tests/test_issue_guide.py`). |
| 차단어 | SB17·Pyzchiva 등은 문서와 이슈 글에 쓸 수 없다. AI가 만든 검색 질문에 제외 제품이나 차단어가 들어가면 그 질문은 보내지 않는다. |

한계도 있다. 모델이 학습으로 실제 사례를 알고 있을 가능성은 막지 못한다. 정답 대조는 어휘 일치로 하는 1차 분류일 뿐이며, 가이드는 사람이 읽고 판정한다.

## SB17을 빼도 자료에 있는 것

SB17 문서를 빼고 원문을 직접 찾아봤다. 정답의 재료는 다른 제품 자료와 지침에 있다.

| 출처 | 내용 |
|---|---|
| EMA reflection paper(tailored clinical approach) p.11 | 전하 차이가 C-말단 Lys 절단 차이 때문이면 carboxypeptidase 처리 시료로 뒷받침할 수 있다 |
| ABP654 EMA p.32, BAT2206 EMA p.25 | 염기성 변이 차이를 C-말단 Lys로 설명하고 CPB 처리로 확인 |
| BMAB1200 EMA p.28·32, FDA p.50–51 | CPB 처리 후 범위 안, C-말단 Lys 차이는 임상 영향 없을 것(비교 PK로 뒷받침) |
| CT-P43 FDA p.55·78 | C-말단 Lys는 체내에서 쉽게 잘려 PK·안전성 영향이 예상되지 않음 |

없는 것은 "C-말단 Lys 차이가 FcRn 결합 차이의 원인"이라는 직접 연결이다. 이것은 모델이 추론해야 한다.

## 고정 질문 방식의 결과 (2026-10-19, gpt-5.6-luna, 별도 확인 서버 8897)

| 회차 | 검색 | 결과 |
|---|---|---|
| 1 | 4건 중 3건 실패 | 답변은 만들어졌지만 '주장 검증' 단계가 출력 한도(주장당 220토큰)에 걸렸다(finish=length). 주장 9–12개, 문장당 94–112토큰을 쟀다. 검증 예산을 주장당 360토큰으로 고쳤다(파이프라인 4.10.4). |
| 2 | 4건 모두 성공 | 인용 공개 자료 35쪽(ABP654·BAT2206·BMAB1200·CTP43 심사 자료와 EMA·FDA·HC 지침), SB17 인용 0, 검사 경고 0. 소요 약 5분 |

2회차 가이드를 직접 읽고 정답과 비교했다.

| 정답 항목 | 판정 | 근거 |
|---|---|---|
| K1 C-말단 Lys 원인 가설 | 못 맞힘 | 원인 후보로 당쇄·산화·전하 변이 등을 넓게 들었다. C-말단 Lys는 ABP654 사례 설명에만 나온다. |
| K2 CPB 확인 시험 | 못 맞힘 | 재현 시험, 직교 분석, 제형·취급 매칭 시험을 제안했다. |
| K3 범위 설정 근거 | 맞힘 | 예상 질의 "107–127% 범위는 어떻게 설정했고 IV와 SC 범위를 다르게 둔 이유는?"이 나왔다. |
| K4 PFS 결과 활용 | 맞힘 | IV에서만 낮고 PFS는 범위 안이라는 점을 원인 분리와 대응 논리에 썼다. |
| K5 영향 없음 결론 | 부분 | EMA 지침의 "범위 이탈이 바이오시밀러성을 자동 배제하지 않는다"(p.8)를 근거로 위험평가 틀을 세웠다. 다만 무영향 결론은 내지 않고 PK 자료가 필요하다고 했다. 어휘 검사는 부정문 안의 단어를 맞힘으로 셌다. |

해석은 이렇다. 보류된 SB17 문서 없이는, 다른 제품 자료에 "FcRn 차이를 C-말단 Lys로 설명한" 사례가 없다. BMAB1200 FDA 품질 심사 p.51의 "C-말단 Lys 차이는 PK 영향이 없을 것"은 이번 답변에 인용되지 않았다. 다음 개선 후보는 1차 답변에서 나온 후보 품질 특성별로(예: 전하 변이·C-말단 Lys) FcRn·PK 연관을 다시 묻는 2단계 검색이다.

## AI 검색 계획 방식의 결과 (2026-10-20, 같은 서버·모델)

고정 질문 4개를 AI가 만드는 검색 계획으로 바꿨다. 순서는 가설 → 질문 4~5개 → 1차 검색 → 추가 질문 0~2개 → 정리다. 정리 지시에는 일반 원칙 세 가지를 넣었다.

1. 다른 제품이 그 특성을 확인한 방법을 이 이슈의 시험 항목에 옮겨 적용한다.
2. 범위 밖이면 범위 산정 근거도 점검한다.
3. 다른 제형 결과가 무엇을 뜻하는지 검토한다.

같은 설정으로 두 번 돌렸다. 각각 검색 7회, 약 9분, 인용 57·59쪽, SB17 인용 0, 검사 경고 0이었다. 판정은 직접 읽고 했다.

| 정답 항목 | 고정 질문(이전) | 실행 A | 실행 B |
|---|---|---|---|
| K1 C-말단 Lys 원인 가설 | 못 맞힘 | 부분: 후보로 들었고 실험에 C-말단 Lys 분석이 있으나, 1순위는 제형 매트릭스 간섭 | 부분: 2순위 후보("glycan·charge, 다른 제품은 C-terminal lysine을 효소처리·charge 분획으로 규명") |
| K2 CPB 확인 시험 | 못 맞힘 | 거의: "변이 분획을 나누거나 효소 처리 후 FcRn 재측정"(효소 이름 없음) | 맞힘: "CPB·PNGase F·neuraminidase 처리 전후 FcRn 재측정, 차이가 줄면 C-말단 Lys/전하 변이 기여" |
| K3 범위 설정 근거 | 맞힘 | 맞힘: IV 10 lot vs PFS 12 lot 대표성, 범위 적정성 질의 | 맞힘: 대조약 10 lot 대표성·사후 확장 금지 |
| K4 PFS 결과 활용 | 맞힘 | 맞힘(보조 증거) | 맞힘(보조 근거) |
| K5 영향 없음 결론 | 부분 | 부분 | 부분 |

K5는 실제 사례에서 추가 자료가 나온 뒤의 결론이다. 이슈 시점의 가이드가 결론을 내지 않고 PK·기능 자료를 묶는 계획을 세운 것은 오히려 맞는 태도로 본다. 남은 차이는 원인 순서다. 두 실행 모두 제형·매트릭스 간섭을 먼저 배제하자고 했다. 실제 사례는 분자 원인(C-말단 Lys)으로 설명됐다.

모델 출력은 매번 달라진다. 이번 계획 전 시험 실행(정리 원칙 추가 전)에서는 K3가 빠지고 K2가 분획 재시험에 그쳤다. 결론을 내리려면 같은 설정으로 더 여러 번 돌려 봐야 한다.
