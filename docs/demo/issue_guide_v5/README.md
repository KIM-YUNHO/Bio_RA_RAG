# 시나리오 v5 — IV vial FcRn 이슈 대응 (RAG 가이드)

사내에서 이슈가 하나 생겼을 때, 공개 규제 문서 RAG가 해결 방향을 얼마나 잘 안내하는지 보는 시나리오다.

## 무엇을 보나

- **이슈:** P17(가명) 130 mg IV vial의 FcRn 상대 결합이 98.0–102.0%로, 계획서 유사성 범위(107–127%) 하한 미만이다. QA가 결과를 유효로 승인했고, SC PFS는 범위 안이다.
- **RAG 가이드:** 같은 성분 바이오시밀러의 공개 심사 자료와 지침에 질문 4개를 던진다. 다른 제품 사례, 원인 규명, 영향 정당화, 지침 요구를 묻는다. AI가 인용된 답변을 다섯 칸으로 정리한다: 원인 규명 방향, 실험 설계, 기관 대응 논리, 예상 심사 질의, 다른 제품 사례.
- **정답 대조(평가용):** 실제 사례인 SB17(Pyzchiva) EMA 공개 심사보고서의 해결과 비교한다. 비교하는 점은 다섯 가지다: C-말단 Lys로 설명, CPB 확인 시험, 범위 설정 맥락, PFS 결과, 영향 없음 결론.

## 정답이 새지 않게 한 장치

| 장치 | 내용 |
|---|---|
| 검색 제외 | 이슈의 `search.exclude_products`(SB17)를 뺀 제품만 검색한다. 답변이 SB17 문서를 인용하면 가이드는 실패로 끝난다. |
| 내부 문서 | 5건(계획서, IV·PFS 결과, QA 기록, 착수 메모)뿐이다. 원인 가설·CEX·CPB 자료는 넣지 않았다. |
| 정답 | `answer_key`는 화면 검토용이다. AI 입력에 들어가지 않는 것을 테스트로 확인한다(`tests/test_issue_guide.py`). |
| 차단어 | SB17·Pyzchiva 등은 문서와 질문에 쓸 수 없다. |

한계도 있다. 모델이 학습으로 실제 사례를 알고 있을 가능성은 막지 못한다. 정답 대조는 어휘 일치로 하는 1차 분류일 뿐이며, 가이드는 사람이 읽고 판정한다.

## 첫 실행 결과 (2026-10-19, gpt-5.6-luna, 별도 확인 서버 8897)

| 회차 | 검색 | 결과 |
|---|---|---|
| 1 | 4건 중 3건 실패 | 답변은 만들어졌지만 '주장 검증' 단계가 출력 한도(주장당 220토큰)에 걸렸다(finish=length). 주장 9–12개, 문장당 94–112토큰을 쟀다. 검증 예산을 주장당 360토큰으로 고쳤다(파이프라인 4.10.4). |
| 2 | 4건 모두 성공 | 인용 공개 자료 35쪽(ABP654·BAT2206·BMAB1200·CTP43 심사 자료와 EMA·FDA·HC 지침), SB17 인용 0, 검사 경고 0. 소요 약 5분 |

2회차 가이드를 직접 읽고 정답과 비교했다.

| 정답 항목 | 판정 | 근거 |
|---|---|---|
| K1 C-말단 Lys 원인 가설 | 못 맞힘 | 원인 후보로 당쇄·산화·전하 변이 등을 넓게 들었다. C-말단 Lys는 ABP654 사례 설명에만 나온다. |
| K2 CPB 확인 시험 | 못 맞힘 | 재현 시험, 직교 분석, 제형·취급 매칭 시험을 제안했다. |
| K3 범위 설정 근거 | 맞힘 | 예상 질의 "107–127% 범위는 어떻게 설정했고 IV와 SC 범위를 다르게 둔 이유는?"이 나왔다. |
| K4 PFS 결과 활용 | 맞힘 | IV에서만 낮고 PFS는 범위 안이라는 점을 원인 분리와 대응 논리에 썼다. |
| K5 영향 없음 결론 | 부분 | EMA 지침의 "범위 이탈이 바이오시밀러성을 자동 배제하지 않는다"(p.8)를 근거로 위험평가 틀을 세웠다. 다만 무영향 결론은 내지 않고 PK 자료가 필요하다고 했다. 어휘 검사는 부정문 안의 단어를 맞힘으로 셌다. |

해석은 이렇다. 보류된 SB17 문서 없이는, 다른 제품 자료에 "FcRn 차이를 C-말단 Lys로 설명한" 사례가 없다. BMAB1200 FDA 품질 심사 p.51의 "C-말단 Lys 차이는 PK 영향이 없을 것"은 이번 답변에 인용되지 않았다. 다음 개선 후보는 1차 답변에서 나온 후보 품질 특성별로(예: 전하 변이·C-말단 Lys) FcRn·PK 연관을 다시 묻는 2단계 검색이다.
