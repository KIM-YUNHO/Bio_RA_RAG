실험은 묶음의 기준이고 결과·기준·의견·결정·조치·질문은 그 안의 정보 종류다. 미팅·계약 항목은 실험에 억지로 넣지 않고 쟁점·상대방에도 연결한다. 각 항목은 원문 문서·버전·절까지 추적한다.

회사·인물·실험·계약·수치·내부 목표는 모두 합성이다. **90~110%는 가상의 사내 개발 목표이며 실제 규제기관 기준·품질 규격·출하 기준이 아니다.** 실제 기관 회신은 없다. 업무별 출력은 사람이 검토할 기대 예시이며 현재 RAG가 생성하거나 평가를 통과한 결과가 아니다. 이 README·시나리오 설명·정리/출력 예시는 향후 원문 검색 코퍼스와 구분한다.
