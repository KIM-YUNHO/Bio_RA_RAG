# DEMO-U01 합성 원문 10개

> 대체된 초안. 아래 수치·실험 사건은 실제 자료에서 가져온 것이 아니므로 현재 시나리오로 채택하지 않는다. [실제 공개자료 기반 v1](../internal_pipeline_v1/README.md)을 우선한다.

버전: 0.1 · 작성: 2026-10-18 KST · 용도: 원문·시나리오 검토

**전부 합성자료다.** 아래 인물·회사·서명·계약·실험·숫자는 사실이 아니다. 가온분석·누리바이오는 이 데모의 가상 회사다. 상대활성 **90~110%는 가상 사내 개발 목표이며 실제 규제기관 기준·품질 규격·출하 기준이 아니다.** 실제 기관 회신·승인자료는 포함하지 않았다.

각 문서에서 `작성/접수일`, `승인일`, `적용일`, `문서 상태`, `데이터 상태`, `시험 유효성`은 서로 다른 정보다. 승인된 문서 안에도 잠정값·인용된 의견·미완료 업무가 있을 수 있다. 모든 시각은 KST다. 절 인용키는 `DEMO-D01@1.0#S1` 형식이다.

### S2. 승인된 가상 내부 목표

기준 ID는 `CRIT-U01-ACT@1.0`이다. **해당 시험의 유효성이 확인되고 CRO의 시험·보고 검토가 완료된 상대활성 값이 90% 이상 110% 이하이면 이 내부 목표 범위 안으로 기록한다.** 자사의 통합 검토 승인은 이 수치 비교와 별개다. 예상값은 가정 비교에만 쓰고, 잠정값은 참고 수치로 분리한다. 유효하지 않은 run은 목표 충족 판정과 결과 합산에 사용하지 않는다.

이 범위는 데모용 사내 개발 목표다. 규제기관의 허용 범위, 실제 품질 규격, 임상적 동등성 기준 또는 출하 기준으로 인용하지 않는다.

### S3. 별도 확인사항

상대활성 외 순도 자료는 누리바이오에서 별도로 받을 예정이다. 이 문서에는 순도 판정식이나 허용 범위를 정하지 않았다. 상대활성 한 항목이 목표 안이더라도 전체 분석 패키지, 제품 유사성 또는 허가 가능성을 판단한 것으로 처리하지 않는다. 사내 통합 검토 승인은 CRO 보고서 승인과 별개다.

### S2. 내부 전용 검토사항

최연구: 최종 제출이 계속 지연되면 대체 CRO 검토를 내부적으로 시작할 수 있다. **업체 교체는 제안 단계이며 결정·통보하지 않았다.** 이 내용은 가온분석 미팅 전달본에 넣지 않는다. 가온분석에는 대조시료 검토 상태, 최종보고 일정, 필요한 자료를 확인한다.

## DEMO-D09 — 재시험 최종보고

| 필드 | 값 |
|---|---|
| 문서 ID / 버전 | `DEMO-D09@1.0` |
| 종류 / 상태 | CRO 최종 결과보고 / `approved` by CRO |
| 작성·접수 / 승인 / 적용 | 작성 2026-09-04 14:00, 자사 접수 16:30 / 가온분석 이분석, 09-04 16:00 / 승인 후 CRO 확정 결과로 사용 |
| 프로젝트 / 실험 / run | `DEMO-U01` / `EXP-U01-ACT-001` / `RUN-A02` |
| 데이터 상태 / run 유효성 | 확정 관측 / `valid` |
| 사내 통합 검토 | 별도 진행 대상; 이 보고서는 그 승인 기록이 아님 |
| 공유 범위 | 자사 프로젝트팀·가온분석 |

### S1. 시험과 결과

RUN-A02는 2026-09-01 수행했다. 대상 배치는 `DU01-B01`, 시험법은 `ACT-M01@1.0`, 대조약 시료는 `REF-U-R01`이다. 대조시료 준비·확인기록을 대조했고 이 run은 유효한 것으로 검토 승인했다. 최종 상대활성 보고값은 **96%**다. 이 값은 해당 run의 확정 관측값이며 예상값이 아니다. 반복값별 수치와 변동성 통계는 이 데모 발췌문에 포함하지 않았다.

### S2. 최초 결과와의 관계

94%를 보고한 RUN-A01은 DEMO-D07에 따라 무효다. RUN-A02의 96%와 합산·평균하지 않았다. 97%는 DEMO-D02의 개발 예상값이며 새 관측값으로 정정하지 않는다. 결과표에는 예상 97%, 무효 run 잠정 94%, 유효 재시험 확정 96%를 각기 다른 항목으로 남긴다.

### S3. 내부 목표 비교와 남은 범위

96%는 DEMO-D01의 가상 내부 목표 90~110% 안이다. 이 문장은 해당 상대활성 항목의 수치 비교다. **CRO 최종보고 승인과 자사의 통합 검토 승인은 다르다.** 사내 검토는 DEMO-D08의 9월 9일 일정에 따라 진행하고, 별도 순도 자료는 이 보고서에 포함하지 않았다. 전체 제품의 유사성·규제 수용·출하 여부는 결론 내리지 않는다.

## DEMO-D10 — 내부 RA 사전 질문 초안

| 필드 | 값 |
|---|---|
| 문서 ID / 버전 | `DEMO-D10@0.1` |
| 종류 / 상태 | 규제기관 미팅 질문 준비 / `draft`, 검토 미완료·미제출 |
| 작성 / 승인 / 적용 | 2026-09-07 16:00 / 없음 / 자사 질문 검토용 |
| 프로젝트 / 실험 | `DEMO-U01` / `EXP-U01-ACT-001` |
| 작성자 / 가상 준비 대상 | 한규제 / FDA와의 향후 미팅을 가정 |
| 공유 범위 | 자사 프로젝트팀 내부 전용; 실제 기관·협력사에 전송하지 않은 초안 |

### S1. 09-07 현재 확인한 사실

RUN-A01의 94%는 무효화됐고, 유효한 RUN-A02의 CRO 최종보고값은 96%다. 96%는 가상 내부 목표 범위 안이지만 사내 통합 검토는 진행 중이다. 별도 순도 자료는 9월 10일 수령 예정이며 아직 없다. 이 초안은 실제 FDA 회신이나 사전 동의를 근거로 작성한 것이 아니다. 관련 공개 지침의 현행성 검토와 원문 연결도 아직 하지 않았다.

### S2. 회사 제안과 질문 후보

**회사 제안 초안:** 최초 run의 무효화 원인·영향·제외 근거를 별도 설명하고, 재시험의 유효성 확인기록과 96% 결과를 함께 제시한다. 미수령 자료와 완료 예정일도 구분한다. 이는 한규제의 제안이며 사내 승인된 최종 제출 전략이 아니다.

**기관 질문 후보 1:** 위와 같은 최초 run 제외와 재시험 결과의 제시 방식에서, 회사가 추가로 설명하거나 입증해야 할 사항은 무엇인가? 질문과 함께 무효화 기록, 재시험 유효성 기록, 비교 가능한 조건을 제시하려 한다.

**기관 질문 후보 2:** 미수령 순도 자료를 포함한 분석 패키지의 적절성을 논의하려면, 회사가 미팅 전에 어떤 자료와 평가 접근을 추가로 정리해야 하는가? 현재 상대활성 한 항목과 가상 내부 목표만으로 전체 패키지가 충분하다고 주장하지 않는다.

### S3. 기관 질문과 협력사 요청의 구분

가온분석에는 대조시료 준비 확인기록, 검토 이력, 무효 run 제외 표시가 완료됐는지 확인한다. 누리바이오의 자료 제출은 자사가 별도 요청한다. 이러한 수령 확인 질문을 그대로 규제기관 질문으로 보내지 않는다. 실제 기관 답변을 예상해 “기관이 수용했다” 또는 “추가 시험이 불필요하다”고 기록하지 않는다. 사내 검토와 공개 근거 확인 후 질문 문구·미팅 목적·제출 범위를 다시 정한다.
