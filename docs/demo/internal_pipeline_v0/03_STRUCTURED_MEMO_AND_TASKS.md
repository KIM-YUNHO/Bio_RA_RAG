### C. 기관 사전 질문 초안 — 내부 RA 검토용·미제출

가상 준비 대상은 FDA이나 실제 회신·사전 동의는 없다. 관련 공개 지침의 현행성과 원문 연결도 아직 검토하지 않았다. 따라서 아래 문장은 특정 가이던스가 허용한 방법이라고 주장하지 않는 질문 초안이다. [`DEMO-D10@0.1#S1`]

**회사 제안 후보:** 무효화 원인·영향·제외 근거와 재시험 유효성·결과를 연결해 설명하고, 미수령 자료와 완료 예정일을 분리해 제시한다. 이는 한규제의 검토 중인 제안이며 승인된 제출전략이 아니다. [KU-18; `DEMO-D10@0.1#S2`]

1. **최초 run 제외·재시험 설명:** “이와 같이 최초 run의 제외 근거와 재시험의 수행 조건·유효성·결과를 함께 제시하려 합니다. 해당 설명에서 추가로 입증하거나 정리해야 할 사항은 무엇입니까?” [KU-19; `DEMO-D10@0.1#S2` 질문 후보 1]

## 4. 이 초안을 다시 메모로 저장할 때

- 원천은 합성 원문 10개다. KU는 그 원천의 작은 주장·업무 단위이며, 세 업무 초안은 KU를 조합한 2차 산출물이다.
- KU-16의 96%를 세 업무가 각각 인용해도 실험 관측이 세 건으로 늘어나지 않는다. `DEMO-D09@1.0#S1`의 같은 결과로 추적한다. RUN-A01의 94%는 별도의 이력이며 중복 제거로 지우지 않는다.
- KU-06·07·18은 의견·제안으로 남긴다. 사람이 이 초안을 검토해도 예상값이 관측값이 되거나 제안이 승인 결정으로 바뀌지 않는다.
- TASK-02의 보고서 접수와 첨부기록 완전성, CRO 승인과 사내 통합 검토, 시험 유효성과 데이터 성숙도를 각각 표시한다.
- 새 기록이 들어오면 관련 KU·브리프의 재검토 필요 여부를 표시하되 T1/T2/T3 당시 스냅샷을 보존한다. 여기 없는 TASK 완료·기관 회신·승인은 추정해 채우지 않는다.
- 01/03과 검토용 설명을 향후 검색 코퍼스에 넣어 별도 근거로 세지 않는다. 실제 적재·평가를 시작할 때는 원문, 파생 메모, 기대 출력의 역할을 구분한다.
