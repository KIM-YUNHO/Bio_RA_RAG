# 현재 전처리·검색 구성의 선정 근거

> **후속 실행 완료:** 현재 계획기를 적용한 100문항의 1·2차 비교와 검증 결과는 [현재 서빙 구성 재평가](CURRENT_SERVING_COMPARISON_2026-10-19.md)에 있다. 이 문서의 아래 표는 선정 당시 준비된 근거를 보존한다.

작성: 2026-10-19 KST. 목적은 **현재 선택한 구성의 타당성을 준비된 비교 결과로 설명하는 것**이다. 본문은 선정 가설 → 직접 비교 → 채택 이유 순서로 구성한다. 새 모델·기능·평가체계를 늘리는 제안은 이번 작업의 우선순위에서 제외하고, 현재 주장에 필요한 연결이 비어 있을 때만 보완한다.

이 문서는 [전체 실험 정리](PERFORMANCE_REVIEW_2026-10-19.md)의 제시용 요약이며, 추가 작업의 우선순위는 이 문서를 따른다. 수치는 기존 산출물을 재확인한 값이다. 새 성능 실험을 수행한 결과는 아니다. 두 서비스의 4.10.3·릴리스04·15,682청크·pgvector 설정을 다시 확인했다. 세부 기준은 [서빙 스냅샷](SERVING_SNAPSHOT_2026-10-19.json)을 따른다.

## 1. 본문에서 전달할 선정 논리

| 영역 | 현재 선택 가설 | 가장 직접적인 준비 근거 | 제시할 결론 |
|---|---|---|---|
| 전처리 | 기본 추출을 유지하고 필요한 영역만 보완·검증하는 H가 적절하다 | G′ 대비 셀79→88, 표16→18, 그림3→4, 기존 성공 셀 손실0 | 누락·불완전 표와 그림 보존을 보완하면서 기존 성공을 유지했다 |
| 1차 검색 | dense와 BM25 결합, 그룹 공통어 제거가 근거 회수에 유효하다 | 같은22문항에서 dense .791 → hybrid .855 → 공통어 제거 .882 | 의미·키워드 검색을 결합하고 불필요한 공통어를 제거하는 선택을 지지한다 |
| 2차 검색 | 제품·기관·영어 사실 질의로 BGE 재정렬 후 RRF 결합이 유효하다 | 같은 계획·풀에서 R@8 .715→.843, nDCG .529→.669, MRR .482→.617 | 동일 후보에서 정답을 더 많이 상위에 배치했다 |
| 전체 구성 | 위 검색 구성과 조건을 보존하는 현재 계획기를 함께 사용한다 | 개발 답변 루브릭278→현재317/384 | 최종 요청 충족 개선과 연결되는 구성을 채택했다 |

전처리·1차·2차·답변은 평가 단위가 달라 하나의 정확도 축에 합치지 않는다. 각 표에 데이터·고정 조건·단위를 표시한다.

## 2. 전처리: H 선정 근거표

제시할 가설: **“정상 기본 추출을 유지하고, 누락·불완전 영역만 선별 보완한 뒤 검증하여 채택한다.”**

같은 ABP654 EMA·FDA·HC 개발 자료의 고정 셀·구절·표 영역·논리 그림을 공통 기준으로 평가한 결과다.

| 비교 구성 | 고정 행·열 셀 일치 /90 | 숫자·단위·기호 구절 /34 | 표 영역 회수 /18 | 그림 보존 /4 | 선택 근거 |
|---|---:|---:|---:|---:|---|
| C: 기본 Docling 계열 추출·보정 | 73 | 29 | 12 | 3 | 기본 추출만으로 남는 누락 확인 |
| G′: 누락 영역 선별 보완 | 79 | 31 | 16 | 3 | 독립 검출·선별 보완의 이득 확인 |
| **H: 누락·불완전 표 보완 + 그림 보존 + 후보 검증** | **88** | **32** | **18** | **4** | **평가 셀·영역 보존이 함께 개선** |

핵심 설명 문장: **“기본 추출에 선별 보완을 적용해 고정 셀73→88개를 회복했고, 마지막 G′/H 직접 비교에서는 셀9개를 추가 회복하면서 기존 성공 셀 손실은0개였다.”**

G′/H는 같은 새 기본 추출·독립 영역 검출을 공유하고 VLM 분기는 각각 새로 실행했다. 따라서 본문의 직접 효과는 G′→H로 제시하고, C→H는 구성 발전의 배경으로 설명한다. H는9회 VLM 작업 중 누락6영역을 추가하고 기존 불완전 표3개 중2개를 교체했다. 나머지1개는 검증에서 거절해 원본을 유지했다.

| G′ → H의 품질·추가 비용 | 준비된 결과 |
|---|---|
| 고정 셀 개선 | 79/90 → 88/90, +10.0%p |
| 기존 통과 셀 손실 | 0개 |
| 표 출력 대응 | G′: TP16/출력17 → H: TP18/출력18 |
| 그림 보존 | 3/4 → 4/4 |
| 기록 시간 | 84.78초 → 107.69초, 추가22.91초 |
| 시간의 정의 | 공유 공통 단계 + 각 분기 실측 합산. 독립 전체 실행 반복평균으로 제시하지 않음 |

이 표는 **“추가 보완 비용을 지불해 누락과 구조 문제를 회복했다”**는 선택을 뒷받침한다. H가 가장 빠른 모델이라는 주장은 사용하지 않는다. 본문 CER는 G′/H 공통이므로 H의 추가 성과는 표·영역·보존으로 설명한다.

근거: [최종 선정 보고서](../preprocessing/FINAL_PREPROCESSING_DECISION_2026-10-14.md), [정확도 원결과](../../pipelines/pipeline_h/vendor/compare_study_standalone/output/abp654_design_20261014_v2/design_accuracy.json), [실행 정책](../../pipelines/pipeline_h/vendor/compare_study_standalone/output/abp654_design_20261014_v2/policy.json), [실행 보고서](../../pipelines/pipeline_h/vendor/compare_study_standalone/output/abp654_design_20261014_v2/DESIGN_COMPARISON_REPORT.md).

## 3. 1차 검색: hybrid와 질의 정리의 선정 근거

제시할 가설: **“dense의 의미 유사도와 BM25의 단어 일치를 결합하고, 제품·기관 그룹 안에서 구별력이 없는 공통어를 제거한다.”**

같은 릴리스04·22문항·저장 계획, 그룹당 상위8, 정답 페이지 기반 recall 비교다. 현재 채택된 요소의 선정 실험이며 최종4.10.3 계획기의 새 측정으로 표기하지 않는다.

| 비교 구성 | 페이지 recall@8 | 채택 설명 |
|---|---:|---|
| dense-only | .791 | 의미 검색 단독 기준 |
| dense + BM25 | .855 | 결합 시 +6.4%p |
| hybrid + 공통어 제거 + BM25 가중치0.5 | .860 | 낮은 키워드 비중의 대안 |

설명 문장: **“dense 단독보다 하이브리드가 근거 회수에 유리했고, 그룹 안 공통어를 제거한 구성이 비교 설정 중 가장 높은 회수율을 보였다.”**

원질문 추가나 BM25 비중 축소도 시험했다는 이력이 현재의 단순한 기본값 선택을 지지한다. 이 표는 회수율에 대한 근거다. fresh-plan Jaccard는 base .629→strip .586이므로 이 실험으로 반복 안정성까지 개선됐다고 쓰지 않는다. 전체 설정 결과는 부록A에 함께 둔다.

근거: [22문항 전체 비교 원결과](../../data/runs/retrieval_stability_2026-10-14/robustness_04.json), [실행 코드](../../eval/retrieval_robustness_eval.py), [현재 프로파일](../../rag/ra_retrieval.py).

두 행은 서로 다른 실험이므로 합산 개선폭을 만들지 않는다. 근거: [문서 목록 비교](../../data/runs/inventory_2026-10-15/recall.json), [통계표 통제 비교](../../data/runs/statistical_table_generalization_2026-10-14/compare_4.9.3_vs_4.9.4_vs_4.9.4-off.json).

## 4. 2차 검색: 현재 BGE·영어 사실 질의·RRF 선정 근거

제시할 가설: **“제품·기관과 사실을 명확히 담은 질의로 후보를 재평가하고, 기존 하이브리드 순위를 함께 사용한다.”**

같은 릴리스04·100문항의 주 지표235묶음·고정 계획·후보 풀40 비교다.

| 2차 구성 | Recall@8 | 기존 nDCG@8 | 기존 MRR | 리랭커 추가 시간 중앙값 |
|---|---:|---:|---:|---:|
| 없음: 하이브리드 순위 | .715 | .529 | .482 | 0 |
| BGE + 한국어 사실 질의 ask_unit + RRF | .804 | .651 | .609 | 1.78초 |
| **BGE + 영어 사실 질의 fquery_unit + RRF** | **.843** | **.669** | **.617** | **1.67초** |
| **현 방식 − 리랭커 없음** | **+12.8%p** | **+.140** | **+.135** | +1.67초 |

설명 문장: **“동일한 후보 풀에서 현재 재정렬 방식은 정답 근거의 상위8 회수와 두 순위 지표를 모두 개선했다.”** 시간은 후보 생성·생성을 제외한 리랭커 추가 시간이다. ask 대비 속도 우위를 주장하기보다 유사한 관측 지연에서 품질이 개선된 것으로 설명한다.

235묶음 기준 상위8 밖 정답은67→37개, 1위 정답은84→115개다. 풀에 있던211개 중 현재 방식은198개(93.8%)를8위 안에 올렸다. 숫자는 [원결과](../../data/runs/retrieval_gold_2026-10-16/model40_bge.json)의 저장 순위에서 집계했고 [집계 JSON](RANK_DIAGNOSTICS_2026-10-19.json)에 보존했다.

이 표의 계획은4.10.2 당시 고정한 것이다. 현재 채택된 재정렬 구성의 비교 근거로 사용하고, 현4.10.3 계획기 전체의 새 검색 점수로 바꾸어 부르지 않는다. 현재 nDCG·MRR의 평가 단위는 각주에 그대로 정의한다. 수치가 좋게 보이도록 산식을 변경하는 작업은 이번 선정 설명에 필요하지 않다.

### 모델 선택을 설명하는 보조표

풀20에서 비교한 결과이며 풀40 본문 표와 구분한다. 모델별 실제 평가한 질의 모드를 표시한다.

| 모델·질의 | Recall@8 | nDCG@8 | MRR | 중앙값 지연 |
|---|---:|---:|---:|---:|
| **BGE fquery_unit** | **.800** | **.646** | **.600** | .8초 |
| BGE ask_unit | .787 | .639 | .597 | .8초 |
| Jina multilingual fquery_unit | .800 | .598 | .538 | .5초 |
| Jina multilingual ask_unit | .787 | .626 | .579 | .4초 |
| Qwen3-0.6B ask_unit | .770 | .597 | .547 | 3.6초 |
| MedCPT fquery_unit | .711 | .459 | .391 | .2초 |

**BGE는 이 평가에서 recall을 유지하면서 순위 품질을 우선하는 선택이었다.** Jina는 더 빠른 대안이었다는 사실도 표시한다. 모델·질의·입력 경로 전체를 비교한 결과로 설명한다. 근거: [모델 비교 기록11:12](../RA_QUERY_HANDLING_LOG.md).

RRF 선택은 별도 ask_unit 통제 비교에서 설명한다. rerank-only은 전체 recall .809, RRF는 .804였으나 세부 질문 recall은 .778→.867, MRR은 .600→.609였다. **RRF는 전체 recall 최대화보다 기존 검색의 강점을 보존하는 선택**으로 제시한다. 근거: [group_rerank 원결과](../../data/runs/retrieval_gold_2026-10-16/group_rerank.json), [선정 기록04:57](../RA_QUERY_HANDLING_LOG.md).
